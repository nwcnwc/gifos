# Security, stability and performance audit — 2026-09-02

Three passes over the tree at `8ba830b` (main): a catalog by eight parallel
readers, each on one surface; a second reading of every finding against the
code, with severities re-rated and each one decided as fixed here, deferred to
a maintainer decision, or recorded as an accepted residual; then the fixes,
each with its guard, on the branch `claude/fable-5-1-kr4fga`.

The surfaces: the app sandbox (SBX), the Cloudflare Workers (WRK), payments
(PAY), crypto and identity (CRY), the desktop and store (DSK), the parsers
(PRS), the mesh and meeting shell (MSH), and CI, scripts and supply chain
(OPS). Every finding that was fixed is described in the commit that fixed it;
this file is the index and the list of what is still open.

## What needs a person

In order of urgency.

1. **Cut a release.** The Critical below (SBX-01) is fixed on the edge build
   only. Every frozen snapshot under `site/versions/` — including the one
   `version.json.current` sends a fresh visitor to — still has it, and
   snapshots are never edited. Until a release is cut from a freeze tag with
   these commits, pinned and default visitors run the old runtime.
2. **Deploy the Workers.** `./deploy-all.sh` deploys relay, cors-proxy and
   mirror and sets the relay's `ABUSE_SALT` secret if it is missing
   (WRK-04). `pay/` changed too and gained a `TREASURY_ADDRESS` var; it is
   not in the script because it is not deployed yet.
3. **Four apps call `prompt()` where a person can reach it** — beepbox
   (clipboard fallback), blockly-games (variable naming), jupyterlite
   (`input()` falls through to the default stdin), svg-edit (image URL,
   hyperlink, three layer dialogs). The sandbox answers `prompt()` with
   `null`, so those features silently do nothing. `test/unit/app-modals.js`
   is RED for exactly these and must stay red until they are ported (the
   `gifosAsk` pattern in `apps/piskel/boot.js`; for Blockly,
   `Blockly.dialog.setPrompt` takes a callback and needs no vendor edit),
   rebuilt, and re-signed — the signing key is not on the box this audit ran
   on, and an unsigned rebuild would be a release red of its own.
4. **The flag day has been taken** (there are no users yet): CRY-01
   (`stretchPw`, PBKDF2 for the room password), CRY-02 (16-character link
   secrets), WRK-03 / CRY-06 (the relay reconnect secret), WRK-10 (monotonic
   signed-order timestamps) and CRY-05 (the owned link's verifier commits to
   the owner's public key) are all in. `DS` is `gifos-net-3`; clients before
   and after it land in different relay sessions, and the relay must be
   deployed with the clients (an old relay ignores `rs` and refuses nothing).

## Deferred, with the reason

- **MSH-5** chat/transcript flood: the maps are uncapped and `renderChat`
  rebuilds the whole log per message. A cap and per-sender rate limit are
  small; the incremental render is not, and the two belong together.
- **CRY-05** owned app links: the verifier tail is a hash of the host secret,
  not of the owner's public key, so binding rests on the gossip ad; a member
  can impersonate the owner toward late joiners. Fix in `resolveMint` (derive
  the owner keypair from the secret, use its verifier) plus the stage signer.
- **CRY-07** FINDLEAF/entry-PLACE carry no signer role; any seated member can
  author them. Mesh protocol change.
- **PAY-03** wallet-transfer invoices can be pre-minted across all dust values
  and matched to other buyers' transfers; binding the invoice to the payer
  address changes the pay-from-any-wallet flow. The per-IP damper narrows it.
- **PAY-07, PAY-09** bearer receipt lookups by order id; verdict cache by
  appId (a test depends on it).
- **SBX-09** `setName` renames the user silently; first-party samples use it.
- **SBX-11** mount teardown is never called; caches never shrink.
- **DSK-06** `allFiles()` pulls every file's bytes to answer metadata
  questions (store page, Settings, reseed). Needs a metadata index.
- **DSK-10/11/12** service-worker cache growth, the online empty-200
  `degrade()`, edge cache swap timing.
- **DSK-14** the purse (`pay.*`) survives "Erase this computer"; erasing paid
  entitlements is a product decision. (The `::art` sibling DB is also left.)
- **WRK-07** `workers_dev` is not pinned off; self-hosters' READMEs rely on it.
- **WRK-09/10/11/18** attachment overflow is silent; a five-minute replay
  window on signed door orders; names reach the relay in `ban[].n`/`by`;
  device-less sockets are unbannable (documented residual).
- **CRY-08/09/10** no nonce on S4 fills, no AAD on `seal()` (documented
  residuals); the OpenPGP path ignores revocation and expiry.
- **PRS-05/06/07** the marker is searched rather than walked and the auth
  code is not compared; inflate peaks at 2× the ceiling; decode is on the
  main thread.
- **OPS-14** actions pinned by tag, no Dependabot.
