# My Mind

A mind map. Click a bubble and type. The map is the save. Nothing is uploaded.

## Keys

- **Tab** — insert a child
- **Enter** — insert a sibling
- **Arrows** — walk the map
- **Space** — fold / unfold children
- **Delete / Backspace** — remove the node (not while typing)
- **Ctrl+Z / Ctrl+Y** — undo / redo (Cmd on a Mac)
- **+ / −** — larger / smaller type
- **Click** a node to select it; **double-click** to type
- **Drag the background** to pan; **wheel** to zoom

On a phone, tap a node, then use the panel on the left (toggle with the chevron) for child / sibling / delete. Long-press also opens a small menu.

## The panel

- **New** — a blank map (replaces the saved one)
- **Open / Save / Save as** — local file on this device, or the in-browser list (same file)
- **Layout** — Map (left and right of the root), Graph (one direction), Tree
- **Shape** — box, ellipse, underline
- **Value** — a number, or a sum / average / min / max of children
- **Status** — yes, no, or autocompute from children
- **Item colour / text colour**

## What is saved

The whole map lives in this file on this device. Edits are written a moment after you make them. Close and come back, the map is where you left it.
