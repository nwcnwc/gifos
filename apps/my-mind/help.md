# My Mind

A mind map. Click a bubble and type. The map is the file. Nothing is uploaded.

## Keys

- **Tab** — insert a child
- **Enter** — insert a sibling
- **Arrows** — walk the map
- **Space** — fold / unfold children
- **Delete / Backspace** — remove the node (not while typing)
- **Ctrl+Z / Ctrl+Y** — undo / redo (Cmd on a Mac)
- **+ / −** — larger / smaller type
- **Click** a node to select it; **click again** or **double-click** to type
- **Drag the background** to pan; **wheel** to zoom

## Phone

Tap a bubble to select it, tap it again to type. The bar at the bottom:

- **Child** — a new idea under the selected bubble
- **Sibling** — a new idea next to it
- **Edit** — type in the selected bubble
- **Delete** — remove it (the root stays)
- **Undo** — take the last change back

Long-press also opens a small menu. The panel on the right (chevron) still has layout, colour, and a blank **New** map.

A blank map is just the centre bubble. Tap it to name the map, then Child to grow it.

## The panel

- **New** — a blank map (replaces the one in this file)
- **Open** — a file on this device, or the in-file list
- **Layout** — Map (left and right of the root), Graph (one direction), Tree
- **Shape** — box, ellipse, underline
- **Value** — a number, or a sum / average / min / max of children
- **Status** — yes, no, or autocompute from children
- **Item colour / text colour**

## What is saved

The whole map lives in this file on this device. Edits are written a moment after you make them. Close and come back, the map is where you left it. A friend who opens a copy of the file sees that same map.
