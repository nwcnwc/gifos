# Monaco Code

A full code editor — the same one inside VS Code. Type JavaScript, TypeScript, JSON, or Markdown. Close the app and the files are still here next time.

## Files

The list on the left is the project. Tap a name to open it. **New** adds a file; **Open** reads one from this device; **More** has rename, delete, and download.

A few sample files are there on the first run so you can type immediately. They are yours to change or delete.

## Editing

This is a real editor, not a text box:

- **IntelliSense** on JavaScript and TypeScript (suggestions, errors, hover).
- JSON is checked as you type.
- **Find** (or Ctrl/Cmd+F). **Format** indents the current file.
- Click a language in More to override the one guessed from the file name.
- Themes: Dark, Light, High contrast. Word wrap is in More, and is on by default on a phone.

On a phone, **Files** opens the list. The editor keeps the rest of the screen, so the keyboard still leaves room to type. Back closes Files, then More, then a name prompt.

## Pair editing

Press **Invite** in the bar above and send the link. Whoever opens it types in the **same files**. You will see their cursor and name. Last typing on a file wins if you both hit the same line. Nothing is uploaded.

## What is saved

Every file in the list. The theme, word wrap, and which file you had open. Sharing the GIF shares the files inside it.
