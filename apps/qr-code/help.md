# QR Code

Type **any text or a URL**. A code appears that a phone can point at. Nothing is uploaded. This is a general maker — for a fridge card with the Wi-Fi name and password, use **WiFi Card** instead.

## Make a code

1. Type in the box. A link, a sentence, a door code, a vCard, anything.
2. The picture updates as you type.
3. Hold the screen up, or press **Download PNG** / **Print**.

**Error correction** is how much of the picture can be scuffed and still read:

- **L** — smallest picture, least spare.
- **M** — a good default.
- **Q** / **H** — more spare, bigger picture.

**Size** is only how large it draws on this screen. **Dark** and **light** are the two colours of the squares. Keep the light colour light — phones need the quiet white border.

## What is saved

The last text, size, colours, and correction level stay in this file on this device. They come back the next time you open it.

Press **Invite** in the bar above the app to show the **same code** in a meeting. People who join see it and can point a phone at it. They do not type their own — the host’s code is the one shown.

Unofficial port of [qrcodejs](https://github.com/davidshimjs/qrcodejs) by davidshimjs.
