    hat.sh v2 files only. The original never left the other person's device either.
      Unlock with

      You decrypt with your private key and their public key — the pair they encrypted to.

      A key pair is two strings. You keep the private key. You can give anyone the public key. They encrypt a file to you; only the private key opens it.

      The keys never leave this tab unless you save them. Closing the app forgets them.

      Unofficial port of hat.sh by sh-dv (MIT). XChaCha20-Poly1305, Argon2id and X25519 via libsodium.js (ISC), packed inside this GIF. Sealed sandbox, no network. A file this app encrypts opens in hat.sh, and the other way around.
