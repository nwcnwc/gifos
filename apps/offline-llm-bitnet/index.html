🧠 Offline Cheap Text LLM BitNetPROVIDER

A cheap text brain for your whole computer — a real LLM answering entirely on this device. No account, no key, nothing sent anywhere.

This app serves your OS

This is a Provider app: it gives GifOS the Cheapest text LLM AI type. Every app that asks the computer for cheap text — Ask AI, Chat drafts, game hints — will use it.

  1. Keep its icon in the Providers folder (a provider only works from there — anywhere else it wears a red ✕).
  2. Open Settings → AI models and set Cheapest text LLM to 📦 BitNet LLM.
  3. The BitNet b1.58 ternary weights (Microsoft Research, ~1 GB) arrive as a hash-pinned download at install and are cached on this computer — after that, everything is offline.

Try it

Engine: llama.cpp via wllama (MIT), compiled to WebAssembly, sealed in this app's sandbox — the worker and wasm load from the app's own bytes, and the sandbox has no network path. Weights: BitNet b1.58 (MIT, Microsoft Research), ternary (−1/0/+1), downloaded once and hash-verified by GifOS. The built-in self-test model is a few MB of deliberately random weights that prove the plumbing without the download.
