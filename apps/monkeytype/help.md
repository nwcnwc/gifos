# Monkeytype

A minimal typing test. Words (or a quote) appear. Type them. Your speed and accuracy show when you finish.

## The test

Pick **time** (15, 30, 60, or 120 seconds), **words** (10, 25, 50, or 100), or a **quote**. **@** adds punctuation. **#** adds numbers. **english** / **english 1k** switches the word list.

Start typing. A caret follows the current letter. Correct letters light up; mistakes go red. Space moves to the next word. Backspace fixes the current word, and can go back to a previous one if it was wrong.

Live speed and accuracy appear after the first keys. When the clock hits zero, or you finish the last word, the result is wpm, acc, raw, consistency, and character counts (correct / incorrect / extra / missed).

## Keyboard

- **Tab** starts a new test.
- **Escape** opens the command line (themes, modes, race).
- **Enter** on the result screen starts the next test.
- On a phone, tap the words so the keyboard comes up.

## Themes

Escape, then type `theme` and a name: serika dark (the default), serika, dracula, nord, 8008, monokai, olivia, carbon, laser, miami, botanical, dark. Fonts are the ones already on the device.

## Race a friend

Press **race a friend**, then **Invite** in the bar above the app, and send the link. The host starts. Everyone gets the same words. Live bars show who is ahead. On a timed test the highest wpm wins; on words or quote, first to finish wins.

Invite is in that bar, not inside this app.

## What is saved

Personal bests for each setting, recent results, and the theme you picked. A test in progress is not kept — leave, and the next open is a fresh one. A race lives on the invite.

An unofficial port of [Monkeytype](https://monkeytype.com).
