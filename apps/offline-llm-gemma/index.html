A cheap text brain for your whole computer — a real LLM answering entirely on this device. No account, no key, nothing sent anywhere.

⚠ Experimental — a demo, not a usable assistant

It exists to prove a real language model can ship inside a GIF, run sealed in the sandbox, and answer with nothing whatever leaving this device. As a chat assistant its speed is not acceptable for common use, and it is not trying to be.

How slow, concretely. The engine runs single-threaded in the browser — GitHub Pages cannot send the COOP/COEP headers that would let it use more than one core — so it writes at about the pace of slow typing. Measured on a phone, one of these three took 362 seconds — six minutes — for a single ordinary question. This one is the fastest of the three — which still means minutes. The first answer of a session is slower again: it loads the weights before writing a word.

Before it says anything it wants a 769 MB download, kept on this device.

What you get for that is privacy that is structural rather than promised — not “we don’t look”, but “there is nowhere for it to go”. If you want a fast, capable assistant instead, point Settings → AI models → Cheapest text LLM at a hosted endpoint; every app that asks for cheap text will use that, and answer in seconds.

This app serves your OS

This is a Provider app: it gives GifOS the Cheapest text LLM AI type. Every app that asks the computer for cheap text — Ask AI, Chat drafts, game hints — will use it.

  1. Keep its icon in the Providers folder (a provider only works from there — anywhere else it wears a red ✕).
  2. Open Settings → AI models and set Cheapest text LLM to 📦 Gemma 3 LLM.
  3. The Gemma 3 1B Instruct weights (Google, ~769 MB) arrive as a hash-pinned download at install and are cached on this computer — after that, everything is offline.

Try it

Engine: llama.cpp via wllama (MIT), compiled to WebAssembly, sealed in this app's sandbox — the worker and wasm load from the app's own bytes, and the sandbox has no network path. Weights: Gemma 3 1B Instruct (Google), used under the Gemma Terms of Use — not MIT; downloaded once from Hugging Face and hash-verified by GifOS. The built-in self-test model is a few MB of deliberately random weights that prove the plumbing without the download.
