🔍→📊 Scanned PDF Tables → Excel

Turn a PDF's tables into an Excel workbook — including a scanned one, read by OCR on your own GPU. Nothing is uploaded, ever.

📄
Drop a PDF here or tap to choose
Text pages are read exactly; scanned pages go through OCR. One sheet per page.

Text pages are read with pdf.js; scanned pages are read by PP-OCR — text detection (DBNet), text recognition (SVTR) and table structure (SLANet), all Apache-2.0 — running on ONNX Runtime over WebGPU, falling back to the CPU where there is no GPU. The spreadsheet is written with SheetJS. Every model is packed inside this GIF and the app is sealed in a sandbox with no network access: the PDF you drop in, and the Excel file that comes out, never leave this device.
