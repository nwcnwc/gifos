# Scanned PDF Tables → Excel

Turn a PDF’s tables into an Excel workbook — including photocopies — on this device. Nothing is uploaded.

## Drop a PDF

Tap the dashed box (or drop a file on it). The app reads **page by page**:

- A page with real text is **read exactly** from that text. Numbers are not guessed.
- A scanned or image-only page is **read as a picture**. That is a reading, not a transcript.

Sheets in the workbook are named `Page 3` or `Page 4 (OCR)`, so a reading of a picture is never mistaken for an exact one later.

## Preview and download

Each page that looks like a table shows a grid. A badge says how it was read:

- **read exactly from the PDF text**
- **OCR + table structure** (rows, columns, and merged cells recovered from the picture)
- **OCR, rows and columns by position** (the picture had no grid the reader could see)

The preview shows the first 12 rows; the rest still go into the file. **Download .xlsx** saves one sheet per page. Empty pages are skipped.

## What it is for

- Insurance **SERFF** rate and rule filings that mix digital tables with scanned exhibits
- Any PDF whose tables you want in a spreadsheet without sending the file anywhere
- Checking a scan before you trust the numbers

## Honest limits

- A faint, skewed, or handwritten page will come back imperfect. Check the numbers that matter.
- Reading is **English**. Other scripts will not come back as proper words.
- The first scanned page can take a while — the reader has to start. Later pages in the same drop are faster.
- It tells you whether it ran on **your graphics chip** or **the processor**.
- A page of prose, not a table, may come back empty or as a rough layout.

## Private

This is a solo tool. There is no Invite. The PDF you drop and the spreadsheet you download stay on this device. Closing the app forgets the last file; drop it again if you need another copy.

The smaller sibling, [PDF Tables → Excel](https://gifos.app/store/pdf-tables), is the tiny text-only option if you never touch scans.
