# QR Scan

Read the **words inside a code** from a still photo. Nothing is uploaded. There is no live camera view — one picture at a time.

## Read a code

- **Take a photo** — GifOS opens its own camera, you shoot a still, the still comes back here.
- **Drop a picture** or **Choose a file** — a JPEG or PNG already on this device.

The picture shows on the left. The decoded text shows on the right. Press **Copy** to put the text on the clipboard.

If nothing is found, try a tighter crop, more light, or a flatter angle. A blurry or tiny code will not read.

## History

Each successful read is kept in a list in this file, on this device only. Tap the trash on a row to drop it. **Clear history** empties the list.

This history never rides an Invite. Invite (in the bar above the app) shares the app itself; each person keeps their own list.

## Not a live scanner

This app never opens a live camera stream. For making a code, use **QR Code**. For a Wi-Fi fridge card, use **WiFi Card**.

Unofficial port of [jsQR](https://github.com/cozmo/jsQR) by cozmo.
