# QR Scan

Read the **words inside a code** from a still photo. There is no live camera view — one picture at a time.

## Read a code

- **Take a photo** — GifOS opens its own camera, you shoot a still, the still comes back here.
- **Choose a picture** — a JPEG or PNG already on this device. On a computer you can also put a picture on this page.

The picture shows on the left. The decoded text shows on the right, with a label if it is a link, a phone number, a contact, or a Wi-Fi login. Press **Copy** to put the raw text on the clipboard.

If the picture will not open, it is not a readable JPEG or PNG. If it opens but nothing is found, try a tighter crop, more light, or a flatter angle. A blurry or tiny code will not read.

**Clear picture** (and the phone Back button) returns to the empty “No picture yet” screen. The history stays.

## History

Each successful read is kept in a list in this file, on this device only. Tap a row to put that text back on screen. Tap the trash on a row to drop it. **Clear history** empties the list.

This history never rides an Invite. Invite (in the bar above the app) shares the app itself; each person keeps their own list.

## Not a live scanner

This app never opens a live camera stream. For making a code, use **QR Code**. For a Wi-Fi fridge card, use **WiFi Card**.

Unofficial port of [jsQR](https://github.com/cozmo/jsQR) by cozmo.
