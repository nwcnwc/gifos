# Snake

Eat the apple. Grow. Do not hit a wall, yourself, or the other snake.

## Objective

Steer the snake. Each apple adds length. Last as long as you can — or, with a friend, be the last one still moving.

## Controls

**Keyboard** — **arrow keys** or **WASD**. You cannot reverse into yourself (no 180° turn) except on the very first key of a life. One extra turn can queue if you already turned this tick.

**Space** or **Enter** starts, pauses, or resumes (solo only). Pause does nothing in a live game.

**Mouse** — the board is not click-to-steer. Use the keys, or the pad if a finger has already touched.

**Phone / touch** — **swipe** the board, or use the **pad** under it (arrows plus pause). The pad appears the first time a finger lands. On a phone the snake also runs a little slower, so a swipe has time to land.

## Rules

The field is a navy grid with walls. Hit a wall or a body and you die. Eating an apple grows you by several cells; the tail does not catch up on those ticks.

You start four cells long, not moving, until the first direction.

**Easy / Medium / Hard / Impossible** is how fast the snake steps. The choice is yours in solo; a live game uses one speed for everyone.

## Scoring

**Length** is the score. **Highscore** is the longest you have been in this file. There are no extra points for speed or apples themselves.

## Solo vs a friend

On your own it is classic Snake. If this file still has a run in it, the welcome sheet offers **Resume** or **New game**.

**Invite** is in the bar **above** the game, not inside it. A friend who opens the link drops onto the **same board**. Two (or more) snakes, **one apple**. Do not hit the other. **Last one still moving wins.** Head-on into the same cell is a double knockout.

Colours tell you apart. Your snake has a bright outline. Difficulty is hidden while you play together — the host starts each round.

If they leave, you are back on a solo board with whatever length you still have.

## What is saved

High score, the speed you picked, and an unfinished **solo** run stay in the file. A live game is not saved. Close mid-race and there is no tape to resume.
