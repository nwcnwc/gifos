# CSS Doodle

A square that fills with a pattern. Remix a snippet. Change a colour or a number. Press **Apply**. That is the whole loop.

## The loop

1. Tap a named snippet under the square — **Checker**, **Tiles**, **Stripes**, **Scatter**, **Fade**, **Dots**, **Rings**, or **Spiral**.
2. The recipe appears in the box. Edit a colour, a grid size, or a number.
3. Press **Apply**. The square becomes yours.
4. **Shuffle** (or tap the square itself) rolls the random bits again so the same recipe lands a new way.
5. **Remix** picks a different snippet at random.

The name in the top-right is the snippet you are on, or **Yours** once the recipe no longer matches one of the eight.

The recipe language is the original doodle dialect: a tiny grid of cells, each painted by the lines you type. You do not need to know it. Changing a hex colour or a number in a snippet is enough.

## Buttons

- **Share the pattern** — start a shared square (see below).
- **Remix** — jump to another snippet.
- **Shuffle** — same recipe, new random rolls.
- **Apply** — paint what is in the box.

There is no zoom. The square fills the stage. On a phone, tap; on a computer, click. There are no extra keyboard commands.

## A live friend

Playing alone is the original toy. The last pattern stays on this device.

Want a friend looking at the same square? Press **Share the pattern** (if you do not already see the friend bar), then **Invite** in the bar above the app, and send the link. You both start from this recipe. When anyone presses **Apply**, **Remix**, **Shuffle**, or taps the square, everyone gets the new pattern.

**← Solo** puts you back on the original toy with the pattern you left.

## What is saved

The last pattern (recipe and shuffle seed) lives in this file. Close it, come back, the square is still there. A live share is the room for that invite, not a second save.
