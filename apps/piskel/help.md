# Piskel

Draw pixel art and sprites, frame by frame. Preview the animation. Export an animated GIF. Everything stays on this device — there is no gallery and no login.

## Canvas and tools

Default size is **32×32**. Resize under the right-hand **RESIZE** gear if you need more.

Left column: **pen size** 1–4, then tools. Hover a tool (or press **?**) for its shortcut.

- **P** pen · **V** vertical-mirror pen · **B** fill · **A** magic bucket (recolor) · **E** eraser
- **L** stroke · **R** rectangle · **C** circle · **M** move
- **S** rectangle select · **Z** shape select · **H** lasso
- **U** lighten · **T** dither · **O** color picker

Primary color is the left swatch, secondary the right. **X** swaps them. Right-click paints with the secondary color.

## Frames and animation

The strip on the left is the **timeline**. **+** adds a frame, the copy icon duplicates the current one. **N** new empty frame, **Shift+N** duplicate, **↑ / ↓** previous / next.

The top-right preview plays the animation. Drag **FPS** (0–24). Onion-skin shows a ghost of the last frame. **1x / Best / Full** changes preview size. The in-app preview plays here; a separate popup window is not available.

## Layers, palettes, transform

**Layers** on the right: add, reorder, rename, merge, delete, opacity.

**Palettes**: pick a set, or **+** to make one. **Transform**: flip, rotate, clone, center, crop.

## Save and export

The sprite **auto-saves** on this device. Close the app, open it later, the frames are where you left them.

Right-hand icons:

- **SAVE** — **Save in Browser** (named copies on this device) or **Save as .piskel** (download a file you can Import later)
- **EXPORT** — animated **GIF**, PNG spritesheet, ZIP of frames, current frame as PNG
- **IMPORT** — a `.piskel`, a picture, an animated GIF, or browse local saves and backups

There is no piskelapp.com. A leftover **Public** checkbox does nothing. The gold **+** at the top starts a new sprite.

## Phone vs mouse

This is a desktop editor. A mouse (or trackpad) is the real way to draw: hover tools, right-click secondary color, keyboard shortcuts. On a phone the three columns are cramped — pinch-zoom the page if you must, but expect to miss tools. GIF export of a large, many-color sprite will hitch the screen while it encodes; pixel-art sizes are the point.

## Private

Solo only. Invite is not used. Saves, palettes, and backups stay on this device. Take a `.piskel` or a GIF with you if you want a copy in your files.
