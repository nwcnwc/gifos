# Carbon

Turn a snippet of code into a **pretty image**. Pick a theme, a background, and export a PNG. There is no account — the snippet and the theme live in this file, so they are still here the next time you open it.

## The window

The grey (or coloured) field is the picture. The dark card is a fake window:

- **Theme** paints the syntax colours (Seti is the default, the one Carbon is known for). Dracula, Night Owl, Nord, One Dark, and the rest are in the same menu.
- **Language** picks the highlighter. **Auto** guesses from what you typed.
- **Background** is the colour around the card. Tap a swatch, or the colour chip for any other hue.
- Type in the window, or **Open** / drop a source file onto the app.

## Settings

**Settings** holds padding, font size, width (or fit-to-line), line numbers, the traffic-light dots, a drop shadow, window style (colour / black-and-white / sharp), and an optional window title.

## Export

**Export PNG** downloads the picture at 1×, 2×, or 4×. **Copy PNG** puts it on the clipboard (if the browser allows; otherwise it downloads). **Copy code** copies the text.

**Keep** stores this snippet under Recents in this file. Export keeps one too. Recents never leave this device.

## With a friend

Press **Invite** in the bar above and send the link. Whoever opens it is on the **same snippet and theme** — when they type, you see it, and the other way around.

## Sample

**Sample** puts back Carbon’s original `pluckDeep` snippet on Seti, on the grey background.
