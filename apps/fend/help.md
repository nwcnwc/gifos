# fend

A notepad calculator that keeps units. Type a line, press **Enter**. The pad stays in this file. Nothing is uploaded.

## Try these

- `1 + 2 * 3`
- `1 ft to cm`
- `5 kg in lb`
- `sqrt(2)`
- `0xFF`
- `4d6` (dice)
- `sin(pi / 2)`
- `1/3 + 1/6`

Answers stay exact when they can (fractions, not a rounded decimal). Mix units in one line. Variables work: `a = 3` then `a * 2`.

## The pad

The history is the notepad: each line you typed, then the answer under it. **Up / Down** walks previous lines. **Clear pad** starts a new page (the old one is gone).

On a phone the prompt sits at the bottom; the history scrolls.

## What is saved

The whole pad (every line and answer) lives in this file on this device. It comes back the next time you open it.

Unofficial port of [fend](https://github.com/printfn/fend) by printfn.
