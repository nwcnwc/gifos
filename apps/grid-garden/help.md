# Grid Garden

Write **CSS grid** to water the carrots and poison the weeds. When the water (or poison) covers the plants, **Next** lights up.

## The garden

The brown square is a 5-by-5 grid. Carrots need water. Weeds need poison. You never drag the plants — you type properties in the editor on the left (on a phone, under the plot).

A property name in the instructions with a dotted underline has a short definition. Tap or hover it.

## How to type

The grey box is a CSS rule. The lines above and below are already filled in. You type the missing declarations, then:

- **Next** — when the beds match, go to the next level. Enter on the last line also tries Next.
- **Ctrl+Enter** / **⌘+Enter** — check and advance.
- **◀ ▶** or the numbered dots — skip around. A filled green dot is a level you have already solved.
- **Reset** (at the bottom of the level list) — wipe saved answers and start at level 1.

There are **28 levels**, from `grid-column-start` through `grid-area`, `order`, and `grid-template`.

## A live friend

On your own this is the original garden. Close it, come back — you are still on that level, with the CSS you typed.

Press **Invite** in the bar above the app and send the link. Whoever opens it lands on **the same plot** and sees **the same CSS**. Either of you can type or change level; the garden stays in one piece. There is no in-app share button.

## What is saved

This file keeps the current level, the CSS you typed on each bed, and which levels you have solved. A live friend's typing lives in the room for that invite, not in the file.
