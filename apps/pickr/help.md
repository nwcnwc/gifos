# Pickr

Pick a color. See it fill the screen. Copy the code.

## Pick

Drag the **palette**, the **hue** bar, and the **opacity** bar with a finger or a mouse. The whole screen washes with the color so you can judge it. A checkerboard shows through when the color is transparent.

Type a code in the picker’s field if you already have one. Tap a **swatch** under the picker for a starting color.

## Copy

Tap a line to copy that format:

- **HEX** — `#E8416C` (includes alpha when the color is not fully opaque)
- **RGB**
- **HSL**
- **CMYK**

A short “Copied …” note confirms it. You can also use the picker’s own **Save** — that only remembers the color in **Recent**, it does not copy.

## Recent

Colors you finish picking (or copy, or Save) land in the **Recent** row, newest first, up to 16. Tap a swatch to return to it. **Clear** empties the row.

## Phone vs mouse

On a phone, drag on the palette — the page will not scroll while you pick. A mouse works the same way. There is no separate “eyedropper from the world”; this is a mixer, not a screen sampler.

## Private

This is a solo tool. There is no Invite. The last color and the recent list stay on this device, inside the app. Close it, open it later, they are still there. OS **Save** on the app bar is a copy of the whole app file, not a color export.

An unofficial port of [Pickr](https://github.com/simonwep/pickr) by simonwep.
