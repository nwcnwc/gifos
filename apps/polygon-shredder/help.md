# Polygon Shredder

A cloud of tiny cubes that shreds into confetti. Move, they pour. Drag, you orbit.

## The loop

1. Move around the picture. Cubes spawn where you point and then tear apart.
2. Drag to orbit the cloud. Pinch or scroll to zoom.
3. Press **Pause** to freeze, **Play** to run again.
4. Open **Knobs** and turn them. Watch the shred change.

On a phone, one finger drags the camera; a tap aims the spawn. Two fingers pinch to zoom. The knobs start closed so the cloud can fill the screen.

## Knobs

- **Factor** — how fast the flakes run.
- **Evolution** — how the flow twists over time.
- **Rotation** — how fast the whole cloud spins.
- **Radius** — size of the bubble that shoves cubes away from the centre.
- **Scale** — how big each flake is.
- **Pulsate** — the bubble breathes in and out.
- **Cloud** — **Lite / Medium / Full**. How many cubes. Lite is kinder to a warm phone.
- **Reset knobs** — back to the original mix.

If this GPU cannot run the shred, you get a sentence saying so — not a black square. A slow GPU shrinks the cloud on its own so the flakes keep moving.

## A live friend

Playing alone is the original toy. The last knobs stay on this device.

Want a friend looking at the same shred? Press **Play together**, then **Invite** in the bar above the app, and send the link. You both start from these knobs. When anyone turns one, everyone gets the new shred.

**← Solo** puts you back on the original toy with the knobs you left. Back closes the knobs first, then leaves a shared square.

## What is saved

The knobs and the cloud size live in this file. Close it, come back, they are still there. A live share is the room for that invite, not a second save.
