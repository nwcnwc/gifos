# PDF Reader

Open a PDF on this page. The last file you opened comes back the next time you open the app (if it fits — about 8 MB). Nothing is sent anywhere.

## Open a file

Press **Open**, or drag a `.pdf` onto the page. A three-page public-domain note is already here the first time, so you can try turning pages before you pick a file of your own.

If the file is locked, a password box appears. The password is used only to open the file on this device.

## Move around

- **Computer:** the arrows, Page Up / Page Down, and Home / End turn pages. `+` and `−` zoom. `0` fits the page to the window. `F` opens Find.
- **Phone:** swipe left or right to turn pages. Pinch to zoom. The buttons at the top do the same jobs with a thumb.

**Fit width** makes the page as wide as the window. **Fit page** shows the whole page.

## Find

Press **Find** (or `F`). Type a word. Matches light up on the page. **Next** / **Prev** jump between them, including on other pages.

## A live friend

Press **Invite** in the bar above the app and send the link. A friend who opens it sees the same file and the same page. When you turn a page, they turn. Press **Point**, then hold on a line — a pointer appears on theirs.

The person who opened the app is the one whose file is shared. A guest who opens a different file sees it only on their own device.

The host can switch the room between *everyone turns pages* and *only the host drives* using the control in the bar above.

## What is saved

The last file (when it fits), the page you were on, and the zoom. Close it, come back, they are still there. Sharing the app file shares that saved reading too.

This copy uses Mozilla's pdf.js (Apache-2.0). It is unofficial — Mozilla did not bless it.
