This app serves your OS

It is a Provider app: instead of doing a job on its own screen, it gives GifOS an ability — the Text → speech AI type. Every app that asks the computer to speak (like Reader in the Tools folder) will use it.

  1. Keep its icon in the Providers folder on your Home Screen — a provider only works from there.
  2. Open Settings → AI models and set Text → speech to 📦 Offline Neural TTS (Kokoro, GPU).
  3. That's it. Apps that speak now speak with this voice, offline.

GPU when you have one, CPU when you don't

Kokoro is a neural transformer voice. On a device with a real GPU it runs on WebGPU; where there is no GPU it runs on the CPU (WebAssembly) instead — same voice, just slower to think. Either way it thinks before it speaks: a passage of audio is generated before it can start playing, so there is a pause at the start of each one.

The voice model is 163 MB, downloaded once and kept on this computer. After that it never touches the network again.

Voice model: Kokoro-82M v1.0 fp16 (Apache-2.0), 163 MB, downloaded once and checked against a SHA-256 pinned in this app. Engine: ONNX Runtime Web (MIT, the WebGPU-capable build) and the espeak-ng phonemizer (GPLv3; the phonemizer.js wrapper is Apache-2.0), both packed inside this GIF and sealed in the app sandbox with no network access.
