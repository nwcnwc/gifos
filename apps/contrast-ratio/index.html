How to use

As you type, the number in the circle updates. A bigger number means the words are easier to read. When a colour is see-through, the number is a range, because what sits underneath changes the result.

This sample text attempts to visually demonstrate how readable this color combination is, for normal, italic, bold, or bold italic text of various sizes and font styles.
