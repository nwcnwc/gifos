# Algorithm Visualizer

Watch an algorithm work one step at a time. Bars swap. Graph nodes light up. A table fills in. You can pause, step, and change the input.

## Pick and play

The list on the left (☰ on a phone) is the catalog. Tap an algorithm. **Play** walks the trace. **Pause** holds a frame. **Prev** / **Next** move one step. Drag the slider to jump. The speed menu is how fast Play advances.

**Space** plays and pauses. Arrow keys step.

## Change the input

Numbers in the array box are the values being sorted or searched. **Run** rebuilds the walk-through from what you typed. **Shuffle** rolls a new random array or graph.

- **Search:** also set the target.
- **Graphs:** Start and End pick the two nodes. Shuffle rebuilds the edges.
- **Knapsack / LCS / Fibonacci / N-Queens:** the extra fields are the problem size or the two strings.

## What you are looking at

- **Chart** — values as bars. Blue is selected. Magenta just changed.
- **Array** — the same values as cells, with their indices.
- **Graph** — nodes and weighted edges. Blue is the visit; green has been left.
- **Log** — a line of English for each interesting step.
- **Grid** — a table (knapsack, LCS, Floyd, N-Queens, flood fill).

## A friend following along

If someone else is in the room, they see the same algorithm, the same input, and your cursor. You drive; they watch. Shuffle and Play stay with the person who opened the app.

## What is saved

The last algorithm and its input. Open the file tomorrow and you are still on Dijkstra with that graph. Sharing the file shares that save.
