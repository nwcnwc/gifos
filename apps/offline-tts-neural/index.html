This app serves your OS

It is a Provider app: instead of doing a job on its own screen, it gives GifOS an ability — the Text → speech AI type. Every app that asks the computer to speak (like Reader in the Tools folder) will use it.

  1. Keep its icon in the Providers folder on your Home Screen — a provider only works from there (anywhere else it wears a red ✕).
  2. Open Settings → AI models and set Text → speech to 📦 Offline Neural Text to Speech.
  3. That's it. Apps that speak now speak with this voice, offline.

What it costs to sound like this

This is a neural voice, not a rule-based synthesiser. It thinks before it speaks: a passage of audio is generated before that passage can start playing, so there is a pause at the start of each one — longer on a phone than on a laptop, and longer the more text it is handed at once.

The voice model is 24 MB, downloaded once and kept on this computer. After that it never touches the network again.

Try the voice

Voice model: KittenTTS Nano 0.8 int8 (Apache-2.0), 24 MB, downloaded once and checked against a SHA-256 pinned in this app. Engine: ONNX Runtime Web (MIT) and the espeak-ng phonemizer (GPLv3; the phonemizer.js wrapper is Apache-2.0), both packed inside this GIF and sealed in the app sandbox with no network access.
